# Tody Prasetya — Pixel Portfolio

## What This Is

A pixel-art-styled personal portfolio website for Tody Prasetya, a Backend/Full Stack Engineer. Built with Next.js, it presents his professional experience, skills, education, and contact info through a retro 16-bit RPG aesthetic — think Chrono Trigger / Final Fantasy vibes with pixel dialogue boxes, a character sprite, and an explorable overworld feel.

## Core Value
