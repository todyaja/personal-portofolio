  <action>
    Add pixel-art utility classes to app/globals.css after the existing CSS variables. Create these utility classes:

    `.pixel-border` — a retro RPG-style border using box-shadow (not border-radius, which is anti-pixel). Use a 2px hard-edge border with `border: 2px solid var(--pixel-border)` and `box-shadow: 4px 4px 0px rgba(0,0,0,0.5)` for that classic RPG dialogue box drop shadow. No border-radius (keep it sharp/rectangular).

    `.pixel-panel` — a dialogue box style: `background-color: var(--pixel-bg-panel)`, `border: 3px solid var(--pixel-border)`, `box-shadow: inset 0 0 0 1px var(--pixel-bg-dark), 6px 6px 0px rgba(0,0,0,0.5)`, `padding: 1.5rem`. This is the primary container for content sections.

    `.pixel-text-shadow` — retro text effect: `text-shadow: 2px 2px 0px rgba(0,0,0,0.8)`.

    `.pixel-btn` — interactive button base: inherits `.pixel-border` styles, adds `cursor: pointer`, `transition: transform 0.1s`, and on `:hover` applies `transform: translate(-2px, -2px)` with `box-shadow: 6px 6px 0px rgba(0,0,0,0.5)` (shadow grows on hover for a "lift" effect), on `:active` applies `transform: translate(2px, 2px)` with `box-shadow: 2px 2px 0px rgba(0,0,0,0.5)` (pressed effect).

    `.pixel-heading` — applies `font-family: var(--font-pixel-heading)`, `text-transform: uppercase`, `letter-spacing: 0.05em`, and `.pixel-text-shadow`.

    `.pixel-body-text` — applies `font-family: var(--font-pixel-body)`, `line-height: 1.6`, `color: var(--pixel-text-primary)`.

    Update app/page.tsx to use these classes: replace the "LOADING..." placeholder with a div that uses `.pixel-panel` containing an h1 with `.pixel-heading` saying "TODY PRASETYA" and a p with `.pixel-body-text` saying "Backend / Full Stack Engineer".
