- Mobile menu: when open, shows links vertically in a dropdown panel below nav
- Use React state (`useState`) for mobile menu toggle

- Add `aria-expanded` to hamburger button

Do NOT use any UI library. Pure React + Tailwind + existing pixel utility classes.
