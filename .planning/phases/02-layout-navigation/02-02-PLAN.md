  <name>Task 1: Add responsive breakpoint utilities to globals.css</name>
  <files>app/globals.css</files>
  <action>
Add responsive utility classes and breakpoint-specific overrides to `app/globals.css`.

Add the following after the existing utility classes:

1. **Responsive pixel-container overrides** (modify existing `.pixel-container`):
   - Base (mobile-first): `padding: 1rem`, `max-width: 100%`
   - `@media (min-width: 640px)`: `padding: 1.5rem`
   - `@media (min-width: 768px)`: `padding: 2rem`, `max-width: 768px`
   - `@media (min-width: 1024px)`: `max-width: 960px`

2. **Responsive pixel-panel overrides**:
   - Base: `padding: 1rem`
   - `@media (min-width: 768px)`: `padding: 1.5rem`

3. **Grid utility classes**:
   - `.pixel-grid` — `display: grid`, `gap: 1rem`
   - `.pixel-grid-2` — `grid-template-columns: 1fr` (mobile), `@media (min-width: 768px)`: `grid-template-columns: repeat(2, 1fr)`
   - `.pixel-grid-3` — `grid-template-columns: 1fr` (mobile), `@media (min-width: 640px)`: `grid-template-columns: repeat(2, 1fr)`, `@media (min-width: 1024px)`: `grid-template-columns: repeat(3, 1fr)`

4. **Responsive text sizing**:
   - `.pixel-heading-responsive` — base `font-size: 0.75rem`, `@media (min-width: 768px)`: `font-size: 1rem`

5. **Overflow prevention**:
   - Add `overflow-x: hidden` to `html` and `body` selectors
   - Add `max-width: 100%` to all `img` elements: `img { max-width: 100%; height: auto; }`

Do NOT remove or modify any existing utility classes beyond the pixel-container padding changes.
