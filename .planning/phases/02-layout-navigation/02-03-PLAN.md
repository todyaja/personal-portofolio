<task type="auto">
  <name>Task 1: Create PixelAvatar component</name>
  <files>components/PixelAvatar.tsx</files>
  <action>
Create a server component (no `"use client"` needed — it is a static image) at `components/PixelAvatar.tsx`.

Component API:
```
interface PixelAvatarProps {
  size?: "sm" | "md" | "lg";
  animated?: boolean;
}
```

Implementation:
- Use Next.js `Image` component from `next/image` for optimization
- Source: `/assets/profile/pfp.jpeg`
- Sizes:
  - `sm`: 64x64 pixels
  - `md`: 128x128 pixels (default)
  - `lg`: 192x192 pixels
- Wrapper: `<div>` with className `pixel-avatar` and size-specific class (`pixel-avatar-sm`, `pixel-avatar-md`, `pixel-avatar-lg`)
- Apply `pixel-border` class to the wrapper for the pixel-art frame
- Add `image-rendering: pixelated` to the image (inherited from body, but ensure it applies)
- If `animated` prop is true (default: false), add `pixel-avatar-animated` class
- Add `alt="Tody Prasetya pixel avatar"` for accessibility

Styling in globals.css (Task 2):
- The wrapper should have:
  - `border-radius: 0` (sharp pixel corners, not rounded)
  - `overflow: hidden`
  - `display: inline-block`
  - Background: `var(--pixel-bg-panel)` behind the image
- The image inside should:
  - `width: 100%`
  - `height: 100%`
  - `object-fit: cover`
  - `image-rendering: pixelated`
  - `filter: contrast(1.1) saturate(1.2)` (slight pixel-art enhancement)

Do NOT use any external sprite sheet or complex animation library. Keep it simple.

   - `.pixel-avatar img` — `width: 100%`, `height: 100%`, `object-fit: cover`, `image-rendering: pixelated`, `display: block`, `filter: contrast(1.1) saturate(1.2)`

   - `@keyframes pixel-idle-bob` — `0%, 100% { transform: translateY(0) }`, `50% { transform: translateY(-3px) }`
