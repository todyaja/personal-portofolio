<task type="auto">
  <name>Task 1: Create TypeWriter client component with cursor and timing</name>
  <files>components/TypeWriter.tsx, app/globals.css</files>
  <action>
    Create `components/TypeWriter.tsx` as a `"use client"` component. Props: `children` (string — the full text to type), `speed` (number, default 50 — ms per character), `delay` (number, default 500 — ms before typing starts).

    Implementation: Use `useState` for `displayedText` (initially empty string) and `isComplete` (initially `false`). Use `useState` for `hasStarted` (initially `false`).

    In `useEffect`: set a timeout for `delay` ms, then set `hasStarted` to `true`. Once started, use `setInterval` with `speed` ms to incrementally append one character from `children` to `displayedText` on each tick. When `displayedText.length === children.length`, clear the interval and set `isComplete` to `true`.

    Cleanup: return cleanup functions from useEffect to clear both timeout and interval on unmount.

    Render: a `<span>` containing `displayedText` followed by a cursor `<span className="pixel-typewriter-cursor">` containing the character "▊". When `isComplete` is `true`, do not render the cursor span at all (it disappears, not just stops blinking).

    Add CSS to `app/globals.css` in a new `/* -- Typewriter Effect -- */` section:
    - `.pixel-typewriter-cursor` with `animation: pixel-cursor-blink 0.7s step-end infinite` and `color: var(--pixel-highlight)`.
    - `@keyframes pixel-cursor-blink` toggling opacity between 1 and 0 at 50%.

    Respect `prefers-reduced-motion`: inside `@media (prefers-reduced-motion: reduce)`, skip the typing animation entirely — set `displayedText` to the full `children` string immediately (set `hasStarted` to true and `displayedText` to full text in the initial useEffect without delay), and do not render the cursor.
  </action>
  <verify>
    <automated>npm run build succeeds with no TypeScript errors</automated>
  </verify>
  <done>
    TypeWriter component accepts text as children, types it character-by-character at configurable speed with configurable start delay, shows blinking cursor during typing, and removes cursor when complete. Respects prefers-reduced-motion.
  </done>
