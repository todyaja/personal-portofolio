<task type="auto">
  <name>Task 1: Create ScrollReveal component with Intersection Observer</name>
  <files>components/ScrollReveal.tsx, app/globals.css</files>
  <action>
    Create `components/ScrollReveal.tsx` as a `"use client"` component. Props: `children` (ReactNode), `staggerIndex` (number, default 0 — used to calculate animation-delay for stagger effect).

    Implementation: Use `useRef` for the wrapper element and `useState` for `isVisible` (initially `false`). In `useEffect`, create an `IntersectionObserver` with options:
    - `rootMargin: "0px 0px 0px 0px"` (triggers when element enters viewport from bottom)
    - `threshold: 0` (trigger as soon as any pixel is visible)
    - `root: null` (use viewport)

    The observer callback: when `entry.isIntersecting` is `true`, set `isVisible` to `true` and call `observer.unobserve(entry.target)` — this ensures play-once behavior (no replay on scroll back).

    Cleanup: disconnect observer on unmount.

    Render: a `<div>` wrapping `children` with:
    - `ref` attached to the wrapper
    - Class `pixel-scroll-reveal` always applied
    - Class `pixel-scroll-reveal--visible` applied when `isVisible` is `true`
    - Inline style `transitionDelay: ${staggerIndex * 100}ms` for stagger effect (100ms between each section)

    Add CSS to `app/globals.css` in a new `/* -- Scroll Reveal Animations -- */` section:
    - `.pixel-scroll-reveal`: `opacity: 0; transform: translateY(40px) scale(0.9); transition: opacity 0.5s ease-out, transform 0.5s ease-out;`
    - `.pixel-scroll-reveal--visible`: `opacity: 1; transform: translateY(0) scale(1);`

    Respect `prefers-reduced-motion`: inside `@media (prefers-reduced-motion: reduce)`, set `.pixel-scroll-reveal` to `opacity: 1; transform: none; transition: none;` — sections are immediately visible without animation.
  </action>

  </verify>
