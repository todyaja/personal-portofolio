<task type="auto">
  <name>Task 2: Implement scroll spy in Navigation component</name>
  <files>components/Navigation.tsx</files>
  <action>
    Modify `components/Navigation.tsx` to add scroll spy functionality. The current `isActive` function only checks `usePathname()` which does not work for same-page anchor links.

    Add scroll spy logic:
    1. Add `useState` for `activeSection` (string, initially `"/"` for Home).
    2. Add `useEffect` that runs on mount. Inside, define the section IDs to track: `["hero", "experience", "skills", "education", "contact"]`. Note: the nav links use `/#about` but the actual section ID is `hero` — map the nav link `/#about` to observe section `hero`. Create a mapping: `{ "/": "/", "/#about": "hero", "/#experience": "experience", "/#skills": "skills", "/#contact": "contact" }`.
    3. Use `IntersectionObserver` to track which section is currently in view. Observer options: `rootMargin: "-80px 0px -60% 0px"` — this means a section is "active" when its top is between 80px from the top and 40% from the top of the viewport (i.e., "near the top of viewport" per CONTEXT.md). `threshold: 0`.
    4. Observer callback: when a section intersects, set `activeSection` to the corresponding nav href. If multiple sections intersect, pick the one closest to the top (the observer will naturally report the one entering the rootMargin zone).
    5. Observe all section elements by their IDs. Cleanup: disconnect observer on unmount.
    6. Replace the `isActive` function: instead of checking `pathname`, check if the link's href matches `activeSection`. For the Home link (`"/"`), it's active when `activeSection` is `"/"` (no section is in view — user is at the very top above hero, or hero is not yet intersecting with the strict rootMargin).

    Update both desktop and mobile nav link rendering to use the new `isActive` check for the `active` class.

    Also fix the nav link mapping: the current `/#about` href should scroll to `#hero` since there is no `id="about"` section. Either change the NAV_LINKS href to `/#hero` or add a scroll handler. Simplest: change `/#about` to `/#hero` in NAV_LINKS.
  </action>
