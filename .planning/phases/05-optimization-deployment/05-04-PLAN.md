  <name>Task 2: Deploy to Vercel and configure domain</name>
  <gate>blocking-human</gate>
  <what-built>
    Vercel deployment configuration (vercel.json) and environment variable template (.env.local.example) are ready.
  </what-built>
  <how-to-verify>
    1. Install Vercel CLI: npm i -g vercel
    2. Run: vercel login (authenticate with GitHub/Email)
    3. Run: vercel --prod (deploy to production)
    4. Note the deployment URL (e.g., https://your-project.vercel.app)
    5. Optional: In Vercel Dashboard → Settings → Domains, add custom domain
    6. If custom domain: Update DNS records at domain registrar (A record or CNAME as instructed by Vercel)
    7. Wait for DNS propagation (up to 48 hours, usually < 1 hour)
    8. Verify HTTPS is auto-provisioned (Vercel handles this automatically)
    9. Test the live URL: verify all pages load, images display, forms work
  </how-to-verify>
  <resume-signal>
    Type "deployed" and provide the live URL when deployment is complete. If using custom domain, confirm DNS is configured and HTTPS is active.
  </resume-signal>
